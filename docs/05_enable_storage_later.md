# Cloud Storage đã sẵn sàng

Đây là tài liệu di sản từ giai đoạn chưa có Blaze. Project hiện dùng Blaze: `student-file-hub-seminar-7a7f2`. Xem [setup.md](setup.md) để điền `.env` và tự cung cấp credentials Admin. Để kiểm tra bucket Admin bật `STORAGE_ENABLED=true`. Nếu tắt, `/api/storage-check` trả `disabled`, không phải lỗi Billing.
